# Atividade 2 - Integridade e Transformação de Dados

Esta pasta mostra um exemplo de realização da atividade 2 sobre análise de integridade e transformação de dados. Diretrizes da atividade 2:

1. Obter um conjunto de dados e desenvolver uma suíte de testes em um arquivo .py para checar a integridade das informações. Veja os exemplos de testes que podem ser feitos na aula M02_integridade_de_dados/2_checagens_iniciais.

2. Caso os dados possuam valores ausentes, apresentar se seria possível imputar valores ausentes e como isso poderia ser feito. Não é preciso implementar a imputação, apenas apresentar a análise.

3. Para cada atributo numérico dos dados:
    - Medir a média, desvio padrão e assimetria (skew). Identifique quais atributos precisam de escalonamento para que os dados fiquem na mesma escala.
    - Aplicar a transformação PowerTransformer do scikit-learn e medir novamente a média, desvio padrão e assimetria. Compare os resultados com os obtidos antes da transformação.
